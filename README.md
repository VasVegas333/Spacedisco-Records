# Spacedisco Records — 2026 Website

A forward-looking, responsive label site built with React + Vite.

## Run locally
```bash
npm install
npm run dev
```

## Updating releases and artists
Edit `src/data/content.js`. The UI renders from this data automatically.

## Design system
Near-black / warm white / acid signal colour, oversized editorial typography, catalogue-first layouts, motion and responsive interactions.

## Next production steps
Replace generated cover treatments with official release artwork, connect streaming/demos/social URLs, add catalogue filtering/search, event data and deployment configuration.
